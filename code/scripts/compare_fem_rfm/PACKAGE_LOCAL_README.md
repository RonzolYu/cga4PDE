# Package-local FEM/RFM/CGA comparison

This directory contains a self-contained input snapshot for the five comparison
cases used in the manuscript.  The case mapping is `C1 -> 01`, `C2 -> 03`,
`C3 -> 06`, `C4 -> 17`, and `C5 -> 08`.  Each case directory under
`data/cga_cases/` contains the accepted-state history, its run summary, the
machine-readable configuration, and the terminal frozen CGA model.  The
dyadic CGA reference values are in `data/cga_snapshot/dyadic_summary.csv`.

The comparison runner reads all of these paths relative to this directory; it
does not require the original workstation layout.  From this directory, after
installing the dependencies in `reproducibility/environment.yml`, run:

```text
python scripts/run_experiments.py --method all --force
python scripts/build_analysis.py
python scripts/build_report.py
```

The commands write raw records to `data/` and derived tables, figures, and
validation files to `artifacts/`.  Existing manuscript artifacts are not
overwritten by this runner.  The output records retain the declared FEM degree
set and RFM seed set from `configs/experiment.json`; any paper figure or table
must be regenerated from the exact input/configuration pair identified by its
manifest.

The copied JSON records use package-relative provenance fields.  They preserve
the numerical values and solver metadata needed for audit, while omitting the
source machine's absolute working-directory names.

This package-local report is an auxiliary audit of the five-case input
snapshot.  Its diagnostic guide lines and local-order plots are not manuscript
baseline figures.  The manuscript figures are generated by the top-level
pipeline under `figures/baselines_recomputed/` and use the stated no-guide-line
and no-order-plot policy.  The package-local configuration deliberately keeps
its own FEM P1/P2/P3 and registered seed set; those records must not be
described as a rerun of the manuscript's P1/P3, ten-seed summary.
