\section{Code and data availability}
\label{sec:code-data}

Code and data are publicly available at \url{https://github.com/RonzolYu/cga4PDE}.
The repository includes problem definitions, numerical parameters, computed
coefficients, and convergence and error-evaluation results. The README and
Supplements S3--S4 specify the statistical samples and give instructions for
regenerating figures and tables, reevaluating the stored approximations, and
performing new coefficient optimizations.
